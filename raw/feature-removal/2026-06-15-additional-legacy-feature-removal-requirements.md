# Additional Legacy Feature Removal Requirements

Пользователь уточнил, что текущие пункты в wiki по вырезке legacy-функционала уже реализованы и должны быть помечены как вырезанные. Новая пачка ниже пока не реализована: сначала нужно глубоко исследовать код, составить подробное ТЗ и добавить его в текущую wiki, а фактическое удаление кода будет отдельным этапом.

Новые функции к безопасной вырезке:

1. Вырезать настройку выплаты, доступную по методу у банков в модальных окнах администратора.
2. Вырезать настройку отправителя уведомлений в модальных окнах администратора в настройках банков.
3. Вырезать метод NSPK / ссылку.
4. Убрать из настроек выплат комиссии; использовать унифицированное сообщение вроде «если платёжный метод не выбран».
5. Убрать функционал callback resend для мерчанта, чтобы нельзя было переотправить все callbacks.
6. Из таблицы логов callback убрать колонку URL и перенести URL в выпадающее меню с дополнительной информацией.
7. Убрать из настроек проекта настройку «Ссылка на техподдержку».
8. Полностью вырезать глазик на странице сделок, который открывает/показывает полные реквизиты.
9. Полностью вырезать функционал каскада из системы и оставить только старые сделки, выплаты и старый API. Удалять безопасно: убрать только каскад и не сломать старый контур.
