# Legacy Feature Removal Requirements

Пользователь запросил создать пошаговое ТЗ на безопасную вырезку набора устаревших функций из проекта и добавить это ТЗ в wiki. Каждый шаг должен содержать две части: вырезка на фронтенде и вырезка на бэкенде.

Главные требования:

- Не выполнять удаление кода сейчас, а подготовить техническое задание.
- Вырезку нужно планировать безопасно, чтобы не сломать существующий функционал.
- Перед каждым удалением нужно глубоко искать по проекту, потому что функционал сильно размазан по фронтенду, бэкенду, ролям, настройкам, API, миграциям, jobs/listeners и ресурсам.
- В конечном ТЗ каждый пункт должен быть отдельным шагом с подпунктами:
  - вырезаем фронтенд;
  - вырезаем бэкенд.

Функции к вырезке:

1. Полностью вырезать аккаунт аналитика и весь его функционал.
2. Полностью убрать автоматическую VIP-систему, где VIP нужно заслуживать обработкой достаточного количества заявок. Оставить только текущий постоянный VIP-статус, который включается навсегда.
3. Убрать выставление команд на странице администратора и на странице пользователя.
4. Вырезать полностью страницу экономики у трейдера и функционал включения/отключения этой страницы администратором.
5. Изменить источник курсов Rapira, точнее полностью удалить Rapira.
6. Полностью удалить страницу статистики реквизитов.
7. Полностью удалить страницу аналитика трейдеров.
8. Страницы API-интеграции полностью удалить в части интерактивных API-запросов через интерфейс. Оставить только документацию, API-токен, скачивание документации и демо платёжной страницы.
9. Вырезать полностью форму оплаты со страницы и вырезать merchants API, оставив только host-to-host API.
10. Убрать из API возможность создавать запрос на автовывод. На странице финансов убрать в колонках external ID и transaction hash. На странице депозитов убрать транзакции и ID.
11. Вырезать полностью функционал категории у мерчантов.
12. Полностью вырезать заметки по пользователям.
13. На странице споров удалить «глазик», который полностью скрывает отображение реквизитов.
14. Вырезать функционал, связанный с приоритетным доступом к выплатам.
15. Полностью вырезать функционал агента, роль агента и весь его функционал.
16. Убрать иконки банков у выплат, потому что там больше нет банков.
17. Убрать новости и отображение новостей у всех ролей, кроме трейдера и тим-лидера.
