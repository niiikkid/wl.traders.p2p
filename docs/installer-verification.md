# Проверка Docker-установщика

## Реально проверенные среды

| Среда | Docker Engine | Compose | Результат |
|---|---|---|---|
| macOS 26.3, Apple Silicon / arm64, Docker Desktop | 29.6.2 | 5.3.1 | Установка и повторный запуск прошли |
| Чистая Ubuntu 26.04.1 LTS, x86_64 | 29.8.0 | 5.5.1 | Автоустановка Docker, установка приложения и повторный запуск прошли |

В обеих средах проверены пакетами:

- Сборка образов и готовность MySQL, Redis, PHP-FPM, Nginx, Horizon, планировщика и службы копирования.
- HTTP `/up`, страница входа и собранный ресурс — 200; вход `admin` открывает административную панель.
- Удаление и пересоздание контейнеров **без удаления томов**: контрольные записи базы, файл в storage и ключи сохранены.
- Повторная установка в ту же папку: база, файлы и исходные пароли сохранены.
- Обновление настроек PHP и подключённых файлов конфигурации после повторной установки.
- Создание резервной копии и импорт её SQL в отдельную проверочную базу; сверены администратор, миграции, контрольная запись, файлы и секреты. Рабочая база не заменялась.

В реальном Chrome проверены ширины 375 и 1100 px, три шага мастера, переключение способов доступа, свой порт, проверка короткого пароля, отправка повторной установки и экран результата. Горизонтального переполнения не обнаружено.

## Автоматические проверки

```bash
python3 -m unittest discover -s installer/tests -p 'test_*.py'
```

35 проверок: параметры, блокировки, защита токеном, повторный запрос, сохранение секретов, исключение чужих папок, занятые порты сайта и мастера (до обращения к Docker, без traceback), локальный Docker context, UTF-8 при Windows-кодировке, пересоздание конфигурации, launcher и структура интерфейса.

## Границы проверки

- **Windows / WSL 2:** подготовлен PowerShell 5.1 launcher, учтены пути, UTF-8 и Linux containers. Реальной Windows-машины для сквозной установки не было.
- **Другие Linux:** предусмотрен запуск с установленными Docker Engine, Compose 2.30+ и Python 3.10+; сквозная проверка выполнена только на указанной Ubuntu.
- **Домен / Cloudflare:** сценарии и проверки конфигурации сохранены, но живого домена, Origin Certificate и доступа к Cloudflare для внешней HTTPS-проверки не было. Локальная проверка Nginx не доказывает работу внешнего Full (strict).
- Это проверка установщика, а не аудит всех платёжных функций или нагрузочное испытание продукта. Режим HTTP предназначен для ознакомления, не для реальных платежей.
