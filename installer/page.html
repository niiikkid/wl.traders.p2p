Выберите адрес и задайте пароль. Остальное уже настроено.

Где открыть приложение?

На этом компьютере — для знакомства. На сервере — для доступа из сети.

Способ доступа
Адрес без http:// и номера порта.
Оставьте как есть. Если порт занят, выберите другой.
Без https:// и пути. Домен нужно зарегистрировать заранее.
Создайте у вашего DNS-провайдера A-запись домена на __SERVER_IP__. Порт 80 сервера должен быть доступен из сети.
  1. В Cloudflare → DNS создайте A-запись на __SERVER_IP__ и включите Proxied (значок облака).
  2. В SSL/TLS → Origin Server → Create Certificate создайте сертификат для указанного домена. Вставьте сертификат и приватный ключ ниже.
  3. В SSL/TLS выберите Full (strict). Включите Always Use HTTPS. Разрешите доступ к портам 80 и 443 сервера.
Не передавайте ключ другим людям. Он нужен для HTTPS между Cloudflare и сервером.

Cloudflare не закрывает прямой доступ к серверу автоматически. Ограничение доступа к серверу настраивается отдельно.

Проверим настройки домена перед следующим шагом.

Доступ администратора

Логин: admin. Сохраните пароль в менеджере паролей.

Не менее 8 символов. Лучше — длинный и уникальный.

Установщик не сохраняет пароль в хранилище браузера. Не отправляйте никому ссылку на эту панель: она даёт доступ к установке.
